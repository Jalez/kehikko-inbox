Kind: feature

- **Add to an epic.** An item about a change no epic names offers "Add to <epic>" in one press when Kehikot can tell which epic it belongs to, "Adopt with <your agent>…" when you picked an agent for Kehikot's own tasks, and an epic and part picker otherwise. A conversation that clearly worked on the change comes along with it.
- **Don't track this.** Kehikot tells you nothing more about that change here; Undo takes it back, and so does Settings › Trackers.
- **What happened, with Undo.** After you add an item to an epic it says so, e.g. "Added to Auth · its Claude Code conversation came along", with Undo for both.
